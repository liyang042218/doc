PHP 基础 ​

变量和数据类型 ​

PHP 支持多种数据类型，包括字符串、整数、浮点数、布尔值、数组、对象和空值。

变量 ​

PHP 中的变量以 $ 符号开头：

php
<?php
$name = "张三";
$age = 30;
$price = 19.99;
$is_active = true;

数据类型示例 ​

php
<?php
// 字符串
$greeting = "你好，世界！";

// 整数
$count = 42;

// 浮点数
$temperature = 98.6;

// 布尔值
$is_logged_in = true;

// 数组
$fruits = ["苹果", "香蕉", "橙子"];

// 空值
$empty_value = null;

运算符 ​

算术运算符 ​

php
<?php
$a = 10;
$b = 3;

echo $a + $b; // 13
echo $a - $b; // 7
echo $a * $b; // 30
echo $a / $b; // 3.333...
echo $a % $b; // 1

比较运算符 ​

php
<?php
$x = 5;
$y = "5";

var_dump($x == $y);  // true（松散相等）
var_dump($x === $y); // false（严格相等）
var_dump($x != $y);  // false
var_dump($x !== $y); // true
var_dump($x > $y);   // false
var_dump($x < $y);   // false

逻辑运算符 ​

php
<?php
$a = true;
$b = false;

var_dump($a && $b); // false（与）
var_dump($a || $b); // true（或）
var_dump(!$b);      // true（非）

控制结构 ​

If-Else 语句 ​

php
<?php
$hour = date("H");

if ($hour < 12) {
    echo "早上好！";
} elseif ($hour < 18) {
    echo "下午好！";
} else {
    echo "晚上好！";
}

Switch 语句 ​

php
<?php
$day = date("l");

switch ($day) {
    case "Monday":
        echo "今天是星期一";
        break;
    case "Tuesday":
        echo "今天是星期二";
        break;
    case "Wednesday":
        echo "今天是星期三";
        break;
    default:
        echo "今天是另外一天";
}

While 循环 ​

php
<?php
$count = 1;

while ($count <= 5) {
    echo "计数：$count<br>";
    $count++;
}

For 循环 ​

php
<?php
for ($i = 1; $i <= 5; $i++) {
    echo "数字：$i<br>";
}

Foreach 循环 ​

php
<?php
$colors = ["红色", "绿色", "蓝色"];

foreach ($colors as $color) {
    echo "颜色：$color<br>";
}

// 带键值对的遍历
$ages = [
    "张三" => 30,
    "李四" => 25,
    "王五" => 40
];

foreach ($ages as $name => $age) {
    echo "$name 今年 $age 岁<br>";
}

函数 ​

基本函数 ​

php
<?php
function greet($name) {
    return "你好，" . $name . "！";
}

echo greet("世界");

带默认参数的函数 ​

php
<?php
function greetWithDefault($name, $greeting = "你好") {
    return "$greeting，$name！";
}

echo greetWithDefault("张三"); // 你好，张三！
echo greetWithDefault("李四", "嗨"); // 嗨，李四！

类型声明 ​

php
<?php
function add(int $a, int $b): int {
    return $a + $b;
}

function greet(string $name): string {
    return "你好，$name！";
}

字符串函数 ​

php
<?php
$str = "Hello World";

// 字符串长度
strlen($str); // 11

// 大小写转换
strtoupper($str); // "HELLO WORLD"
strtolower($str); // "hello world"

// 截取子字符串
substr($str, 6, 5); // "World"

// 字符串替换
str_replace("World", "PHP", $str); // "Hello PHP"

// 查找字符串位置
strpos($str, "World"); // 6

PHP 安装指南 ​

学习如何在不同平台上安装和配置 PHP。

Windows 安装 ​

使用 XAMPP ​

XAMPP 是一个免费的、易于安装的 Apache 发行版，包含 PHP、MariaDB 和 Perl。

  1. 从官方网站下载 XAMPP
  2. 运行安装程序
  3. 选择组件（至少：Apache、PHP、MySQL）
  4. 选择安装目录（例如 C:\xampp）
  5. 完成安装

使用 WAMP ​

WAMP 是另一个基于 Windows 的开发环境。

  1. 下载 WAMP 服务器
  2. 运行安装程序
  3. 提示时选择浏览器和文本编辑器
  4. 完成安装

使用 PHP 安装程序 ​

  1. 从 php.net 下载 PHP
  2. 解压到 C:\php
  3. 将 PHP 添加到系统 PATH
  4. 配置 php.ini

macOS 安装 ​

使用 Homebrew ​

bash
# 安装 PHP
brew install php

# 安装特定版本
brew install php@8.2

# 启动 PHP 内置服务器
php -S localhost:8000

使用 MAMP ​

下载并安装 MAMP，它包含 Apache、MySQL 和 PHP。

Linux 安装 ​

Ubuntu/Debian ​

bash
# 更新软件包列表
sudo apt update

# 安装带 Apache 的 PHP
sudo apt install php libapache2-mod-php

# 安装带 MySQL 的 PHP
sudo apt install php-mysql

# 安装常用扩展
sudo apt install php-curl php-json php-mbstring php-xml

CentOS/RHEL ​

bash
# 安装 EPEL 和 Remi 仓库
sudo dnf install epel-release
sudo dnf install dnf-utils

# 安装 PHP
sudo dnf install php php-mysql php-json php-mbstring

# 重启 Apache
sudo systemctl restart httpd

验证安装 ​

命令行 ​

bash
# 检查 PHP 版本
php -v

# PHP 版本和配置信息
php -i

# 检查已安装的模块
php -m

创建信息页面 ​

php
<?php
phpinfo();

将其保存为 info.php 在网站根目录，通过浏览器访问。

配置 ​

php.ini 位置 ​

bash
# 查找 php.ini 位置
php --ini

基本配置 ​

ini
; 最大执行时间
max_execution_time = 30

; 内存限制
memory_limit = 128M

; 文件上传大小
upload_max_filesize = 2M
post_max_size = 8M

; 显示错误（仅开发环境）
display_errors = On
error_reporting = E_ALL

; 时区
date.timezone = Asia/Shanghai

开发服务器 ​

PHP 内置服务器 ​

bash
# 启动开发服务器
php -S localhost:8000

# 指定文档根目录
php -S localhost:8000 -t /path/to/public

# 使用路由脚本
php -S localhost:8000 router.php

路由脚本示例 ​

php
<?php
// router.php
$uri = parse_url($_SERVER["REQUEST_URI"], PHP_URL_PATH);

if ($uri === "/" || $uri === "/index.php") {
    require __DIR__ . "/public/index.php";
} elseif ($uri === "/api/users") {
    require __DIR__ . "/api/users.php";
} else {
    http_response_code(404);
    require __DIR__ . "/public/404.php";
}
